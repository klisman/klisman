## 🚀 Featured projects

### 🗳️ [Ledger Vote](https://github.com/klisman/ledger-vote-solana) — *a vote a whale cannot buy*

Token-weighted polls fail when the biggest wallet buys the result one token at a time, then moves the balance and votes again. Ledger Vote snapshots the weight as `floor(sqrt(balance))` when the vote is cast, so extra tokens buy less power, and freezes that token account until the poll locks or expires.

`TypeScript · React · Next.js · Solana`

### 🔐 [Vesting Vault](https://github.com/klisman/vesting-vault-solana) — *grants that do not live in a spreadsheet*

A token grant tracked off-chain can be paid early, paid twice, or taken back with no record of what had already vested. Vesting Vault unlocks tokens on a line, holds the first slice behind an optional cliff, and lets the creator revoke only what the clock has not released.

`TypeScript · Node.js · Solana`
